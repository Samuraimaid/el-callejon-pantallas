================================================================================
  EL CALLEJON - PC SERVIDOR (pantallas digitales + musica)
================================================================================

INSTALACION (una sola vez en el PC del restaurante)
---------------------------------------------------
1. Copie esta carpeta completa a:
      C:\EL_CALLEJON_POS

2. Doble clic (como Administrador si lo pide):
      INSTALLAR.bat

3. El instalador:
   - Revisa el PC e instala Docker / Python si faltan
   - Abre puertos de red (5173, 8000, 8788)
   - Levanta la base de datos y el sistema
   - Enciende la musica (Me gusta o shuffle todas)
   - Abre el navegador con codigos QR
   - Deja el arranque automatico al ENCENDER el PC
   - Programa backup semanal (domingo 03:00)

----------

    - Sistema en linea

COMANDOS UTILES
---------------

  scripts\Backup-CallejonUSB.bat   Copia a USB
  scripts\Snapshot-Callejon.bat    Snapshot limpio ahora

LOGS

REQUISITOS
----------
  Windows 10/11 64-bit, 8 GB RAM recomendado, Docker Desktop,
  red local (Wi-Fi o cable) compartida con las Smart TVs.
