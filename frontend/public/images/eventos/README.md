# Media de plantillas de evento

Imágenes de muestra (Unsplash, uso de referencia/demo) y música corta en
`/audio/eventos/*.mp3` (clips ~15 s).

Plantillas del sistema:

| id | Uso |
|----|-----|
| `cumpleanos` | Fiesta, bounce-in, dorado/rosa |
| `boda` | Elegante, fade-up, marfil |
| `corporativo` | Profesional, slide-left, azul |
| `graduacion` | Orgullo, zoom-in, navy/ámbar |
| `navidad` | Temporada, sparkle, verde/rojo |

Aplicar desde Centro de Control → Monitoreo → **Plantillas**.
